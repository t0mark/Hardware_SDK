The ROS 2 version of the inspire_hand package supports the use of Intime Robotics' dexterous hands and grippers on the ROS platform. We have only tested it on Ubuntu 22.04 ROS 2 humble. Other ROS environments will require further testing.


2. In order for the program to run properly, you need to perform the following environment configuration operations: (This is required for the first execution and is not required after the configuration is completed)

     1) Install the ROS2 humble version environment. The specific installation method is as follows:
       (1) Use Xiaoyu ROS one-click installation, the installation process reference:  https://blog.csdn.net/weixin_55944949/article/details/140373710?fromshare=blogdetail&sharetype=blogdetail&sharerId=140373710&sharerefer=PC&sharesource=weixin_60461072&sharefrom=from_link
       
       The installation process is to download the script：wget http://fishros.com/install -O fishros && . fishros

       (2）Install the Modbus library using the terminal command: sudo apt-get install libmodbus-dev.
Note: If any dependencies are missing, download them based on the error message displayed during the CMake compilation.

    2）Create a catkin working directory
      Terminal Commands：mkdir -p ~/inspire_hand_ws/src
                cd ~/inspire_hand_ws
                colcon build
                source install/setup.bash  (Used when each terminal starts to help you find the ROS installation directory)

    3）Place inspire_hand_ros2.zip in the /src folder under the inspire_hand_ws directory and unzip it.
       Terminal command: cd ~/inspire_hand_ws/src
             unzip inspire_hand_ros2
                 Place the unzipped inspire_hand_modbus_ros2 and service_interfaces files into inspire_hand_ws/src and delete the inspire_hand_ros2 folder.
                 
    4）Recompile the installation package
       Terminal Commands：colcon build --packages-select service_interfaces
        colcon build --packages-select inspire_hand_modbus_ros2
Note: Avoid using sudo gedit ~/.bashrc to add excessive source commands to your bash file to prevent environment variable conflicts. Also, minimize duplicate package names, such as "service_interfaces." Otherwise, you may encounter message format quoting errors or node activation errors.

3.1 Using Dexterous Hands    
   1）Use a network cable to connect inspire_hand to the corresponding host, change the IPv4 address to 192.168.11.222, and the subnet mask to 255.255.255.0; if ping 192.168.11.210 returns data, the connection is successful. Otherwise, check whether the line connection is normal.。

    2) Start using the inspire_hand_modbus_ros2 package. Note: You need to open a new terminal and execute the command: source install/setup.bash
                                                      ros2 run inspire_hand_modbus_ros2 hand_modbus_control_node 
 
           (1) Set ID ------ ID range 1-254
	ros2 service call /Setid service_interfaces/srv/Setid "{id: 2, status: 'set_id'}"

	   (2) Set the baud rate ------ parameter redu_ratio range 0-4
	ros2 service call /Setreduratio service_interfaces/Setreduratio "{redu_ratio: 0,id: 1, status: 'set_reduratio'}" 

          (3) Set six drive positions ------ parameter pos range 0-2000
	ros2 service call /Setpos service_interfaces/srv/Setpos "{pos0: 1000,pos1: 1000,pos2: 1000,pos3: 1000,pos4: 1000,pos5: 1000,id: 1, status: 'set_pos'}"

	  (4) Set speed ------ parameter speed range 0-1000
	ros2 service call /Setspeed service_interfaces/srv/Setspeed "{speed0: 50,speed1: 50,speed2: 50,speed3: 50,speed4: 50,speed5: 50,id: 1, status: 'set_speed'}"

	 (5) Set the angle of the dexterous hand --- the parameter angle range is 0-1000
	ros2 service call /Setangle service_interfaces/srv/Setangle "{angle0: 1000,angle1: 1000,angle2: 1000,angle3: 1000,angle4: 1000,angle5: 1000,id: 1, status: 'set_angle'}"

	   (6) Set the force control threshold ------ parameter force range 0-1000
	ros2 service call /Setforce service_interfaces/srv/Setforce "{force0: 0,force1: 0,force2: 0,force3: 1000,force4: 0,force5: 0,id: 1, status: 'set_force'}"

	   (7) Set the current threshold ------ parameter current range 0-1500
	ros2 service call /Setcurrentlimit service_interfaces/Setcurrentlimit "{current0: 1500, current1: 1500, current2: 1500, current3: 1500, current4: 1500, current5: 1500,id: 1, status: 'set_currentlimit'}"
  
	   (8) Set the power-on speed ------ parameter speed range 0-1000 (executed after power off and then power on again)
	ros2 service call /Setdefaultspeed service_interfaces/srv/Setdefaultspeed "{speed0: 1000,speed1: 1000,speed2: 1000,speed3: 1000,speed4: 1000,speed5: 100,id: 1, status: 'set_defaultspeed'}"

	   9) Set the power-on control threshold --- parameter force range 0-1000 (executed after power-off and power-on again)
	ros2 service call /Setdefaultforce service_interfaces/srv/Setdefaultforce "{force0: 1000, force1: 1000, force2: 1000, force3: 1000, force4: 1000, force5: 1000}"

	   (10) Set the power-on current threshold --- parameter current range 0-1500 (executed after power off and then power on again)
	ros2 service call Setdefaultcurrentlimit service_interfaces/srv/Setdefaultcurrentlimit "{current0: 1500, current1: 1500, current2: 1500, current3: 1500, current4: 1500, current5: 1500}"

  	  (11) Force sensor calibration ------ This command needs to be executed twice (after execution, the palm will be fully opened and then the force calibration will be performed)
	ros2 service call /Setforceclb service_interfaces/srv/Setforceclb "{id: 1, status: 'set_forceclb'}" 

	   (12) Dexterous Hands Clear Errors
	ros2 service call /Setclearerror service_interfaces/srv/Setclearerror "{id: 1, status: 'set_clearerror'}" 

	   (13) Restore factory settings
	ros2 service call /Setresetpara service_interfaces/srv/Setresetpara "{id: 1, status: 'set_resetpara'}"  

	  (14) Save parameters to FLASH
	ros2 service call /Setsaveflash service_interfaces/srv/Setsaveflash "{id: 1, status: 'set_saveflash'}" 

	  (15) Read the position value set by the driver
	ros2 service call /Getposset service_interfaces/srv/Getposset "{id: 1, status: 'get_posset'}" 

         (16) Read the set dexterous hand angle value
	ros2 service call /Getangleset service_interfaces/srv/Getangleset "{id: 1, status: 'get_angleset'}" 

	  (17) Read the set force control threshold
	ros2 service call /Getforceset service_interfaces/srv/Getforceset "{id: 1, status: 'get_forceset'}"

         (18) Read the current value
	ros2 service call /Getcurrentact service_interfaces/srv/Getcurrentact "{id: 1, status: 'get_currentact'}"

         (19) Read the actual position value of the driver
	ros2 service call /Getposact service_interfaces/srv/Getposact "{id: 1, status: 'get_posact'}"

	 (20) Read the actual angle value of the dexterous hand
	ros2 service call /Getangleact service_interfaces/srv/Getangleact "{id: 1, status: 'get_angleact'}"

         (21) Read the actual force
	ros2 service call /Getforceact service_interfaces/srv/Getforceact "{id: 1, status: 'get_forceact'}"

        (22) Read temperature information
	ros2 service call /Gettemp service_interfaces/srv/Gettemp "{id: 1, status: 'get_temp'}"

        (23) Read fault information
	ros2 service call /Geterror rvice_interfaces/srv/Geterror "{id: 1, status: 'get_error'}"
	
	(24) Read the set speed value
	ros2 service call /Getspeedset service_interfaces/srv/Getspeedset "{id: 1, status: 'get_speedset'}"
	(25) Read status information
	ros2 service call /Getstatus service_interfaces/srv/Getstatus "{id: 1, status: 'get_status'}"
	
	(26) Gesture sequence
	 ros2 service call /Setgestureno service_interfaces/srv/Setgestureno "{gesture_no: 1,id: 1, status: 'setgesture'}"
	
    5) ROS Topic Usage Example: Reading Dexterous Hand Tactile Sensor Data in Real Time
        Open a new terminal and execute the following command: source install/setup.bash
1.ros2 run inspire_hand_modbus_ros2 handcontrol_topic_publisher_modbus.py
2.ros2 run inspire_hand_modbus_ros2 handcontrol_topic_subscriber_modbus.py
This example will print the transmission frequency and the current tactile sensor data for the entire hand in real time.
3.ros2 run inspire_hand_modbus_ros2 inspire_hand_modbus_topic.py
This example will publish topics for setting angle, speed, and force, and reading angle, tactile, force, and cylinder temperature. Topic call example:
Set angle: ros2 topic pub -1 /set_angle_data service_interfaces/msg/SetAngle1 "{finger_ids: [1,2,3,4,5,6], angles: [1000,1000,1000,1000,1000,1000]}"
Read angle: ros2 topic echo /angle_data

     6) ROS service usage example: The script calls the service contained in service_interfaces/srv: Setpos
     You need to open a new terminal and execute the terminal command:    source install/setup.bash
                                            ros2 run inspire_hand_modbus_ros2 hand_control_client_modbus_node
